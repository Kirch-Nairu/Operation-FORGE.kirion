# ChatGPT Mode — Project Factory

Use when Kirch wants to build a new project, variant, module, Salryn skin, business line, or internal tool.

## Non-negotiable rule

Do not implement yet.

## First output

Produce:

1. Product hypothesis
2. First-user hypothesis
3. One daily workflow hypothesis
4. MVP include list
5. MVP exclude/park list
6. Cost-free dependency scan
7. Salryn Standard parent reuse map
8. Open questions
9. Draft Project Constitution
10. Approval gate

## Question standard

Ask concrete questions that change implementation.

Bad:

```text
What features do you want?
```

Good:

```text
Should V1 allow partial payment, or only full payment posting?
```

## Approval rule

Only after Kirch replies APPROVED or clearly approves a revised constitution may phase planning begin.

## Anti-feature-stacking rule

If Kirch adds a feature before V1 is proven, classify it.

Never silently include it.
