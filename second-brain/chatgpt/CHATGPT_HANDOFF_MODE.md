# ChatGPT Mode — Handoff Writer

Use to turn notes, logs, screenshots, or Codex/Cursor output into a durable handoff.

## Rules

- Do not invent SHA.
- Do not upgrade uncertainty into proof.
- Mark skipped gates as NOT RUN.
- Mark hardware/UI checks as manual unless actually proven.
- Preserve parked scope.

## Required sections

- Lane
- Branch
- Starting SHA if known
- Ending SHA if known
- Status
- What changed
- Files touched
- Gates run
- Gates not run
- Manual checks needed
- Parked scope
- Known risks
- Next recommended lane
