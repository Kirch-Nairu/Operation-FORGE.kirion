# Threat Register

Threats model adversarial, misuse, or abuse conditions. A threat may create one or more risks; a realized threat may create an incident.

## Threat record dimensions

- asset
- actor / capability
- entry surface
- trust boundary crossed
- abuse path
- consequence
- existing controls
- mitigation
- verification
- residual risk
