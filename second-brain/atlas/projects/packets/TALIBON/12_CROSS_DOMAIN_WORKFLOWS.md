# Talibon Cross-Domain Municipal Workflows

The platform's strongest systems property is propagation across domains rather than isolated forms.

Examples from the core SSOT:
- employee transfer → office membership → permissions → open-work reassignment → property review → calendar access → supervisor notification → audit event
- offboarding → clearance → work reassignment → property return → payroll finalization → access revocation → archival → audit
- correspondence → receive → register → classify → route → act → release → archive, with deficiency/escalation paths
