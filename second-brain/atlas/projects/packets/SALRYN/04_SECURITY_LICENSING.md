# Salryn Security and Licensing

The PRE-I model separates Host and Terminal entitlements, uses signed local licensing, keeps activation cloud-independent, and treats operator UI restrictions as subordinate to backend authority. Licensing state, terminal authority and privileged store actions require auditable enforcement rather than copy-level controls.
