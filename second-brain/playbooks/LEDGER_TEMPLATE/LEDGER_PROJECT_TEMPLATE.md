# Salryn Ledger Project Template

## Hypothesis

Salryn Ledger is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- account/category setup
- income and expense entry
- cash movement log
- basic balance report
- export

## Park by default

- full accounting compliance
- tax filing automation
- bank sync

## Cost-free rule

No paid services are required for V1 unless explicitly approved.

## Parent reuse map

Usually reuse:

- app shell
- local API host
- SQLite setup
- auth/session
- permissions
- audit log
- reports pattern
- backup pattern where applicable

Before coding, produce a Project Constitution and implementation surface map.
