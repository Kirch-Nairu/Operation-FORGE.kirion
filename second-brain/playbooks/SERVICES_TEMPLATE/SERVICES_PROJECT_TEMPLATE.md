# Salryn Services Project Template

## Hypothesis

Salryn Services is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- service catalog
- customer records
- job/order ticket
- payment posting
- service receipt
- basic reports

## Park by default

- scheduling automation
- SMS reminders
- cloud booking portal

## Cost-free rule

No paid services are required for V1 unless explicitly approved.

## Parent reuse map

Usually reuse:

- app shell
- local API host
- SQLite setup
- auth/session
- permissions
- audit log
- reports pattern
- backup pattern where applicable

## Phase 0 output

Before coding, produce a Project Constitution and implementation surface map.
