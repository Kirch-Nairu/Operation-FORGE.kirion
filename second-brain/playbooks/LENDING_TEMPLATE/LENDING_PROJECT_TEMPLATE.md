# Salryn Lending Project Template

## Hypothesis

Salryn Lending is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- borrower records
- loan creation
- payment schedule
- payment posting
- balance tracking
- due/overdue view
- payment acknowledgment snapshot
- basic reports
- role guard
- audit trail

## Park by default

- SMS reminders
- online payment
- cloud sync
- credit scoring
- legal automation
- mobile borrower portal

## Cost-free rule

No paid services are required for V1 unless explicitly approved.

## Parent reuse map

Usually reuse:

- app shell
- local API host
- SQLite setup
- auth/session
- permissions
- audit log
- reports pattern
- backup pattern where applicable

## Phase 0 output

Before coding, produce a Project Constitution and implementation surface map.
