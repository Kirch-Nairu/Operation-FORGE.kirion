# Salryn Food Project Template

## Hypothesis

Salryn Food is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- menu items
- order ticket
- cashier checkout
- receipt snapshot
- daily food sales report

## Park by default

- delivery app integration
- online ordering

- permissions
- audit log

- backup pattern where applicable
