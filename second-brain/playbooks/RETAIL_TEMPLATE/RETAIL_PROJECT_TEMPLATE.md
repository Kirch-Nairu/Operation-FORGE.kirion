# Salryn Retail Project Template

## Hypothesis

Salryn Retail is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- product catalog
- checkout
- receipt snapshot
- inventory movement
- daily sales report
- cashier/admin roles

## Park by default

- cloud sync
- BIR/eSales production
- online payments

## Cost-free rule

No paid services are required for V1 unless explicitly approved.

## Parent reuse map

Usually reuse:

- app shell
- local API host
- SQLite setup
- auth/session
- permissions
- audit log
- reports pattern
- backup pattern where applicable

## Phase 0 output

Before coding, produce a Project Constitution and implementation surface map.
