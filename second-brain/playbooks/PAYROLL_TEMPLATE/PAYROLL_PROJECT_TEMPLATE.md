# Salryn Payroll Project Template

## Hypothesis

Salryn Payroll is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- employee records
- pay period setup
- earnings and deductions
- payroll draft
- payroll finalization
- payslip snapshot
- payroll reports
- role guard
- audit trail

## Park by default

- government submission automation
- bank upload
- cloud portal
- biometrics integration
- tax/legal automation unless verified

## Cost-free rule

No paid services are required for V1 unless explicitly approved.

## Parent reuse map

Usually reuse:

- app shell
- local API host
- SQLite setup
- auth/session
- permissions
- audit log
- reports pattern
- backup pattern where applicable
