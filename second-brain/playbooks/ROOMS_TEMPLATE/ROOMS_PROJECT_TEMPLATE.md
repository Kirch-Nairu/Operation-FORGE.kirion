# Salryn Rooms Project Template

## Hypothesis

Salryn Rooms is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- room records
- guest check-in
- stay charges
- payment posting
- receipt
- occupancy report

## Park by default

- OTA integration
- online booking engine
- card payment gateway

## Cost-free rule

No paid services are required for V1 unless explicitly approved.

## Parent reuse map

Usually reuse:

- app shell
- local API host
- SQLite setup
- auth/session
- permissions
- audit log
- reports pattern
- backup pattern where applicable

Before coding, produce a Project Constitution and implementation surface map.
