# Salryn Business Suite Project Template

## Hypothesis

Salryn Business Suite is a Salryn-derived local-first product built from Salryn Standard patterns.

## MVP includes

- shared shell
- module registry
- shared identity
- shared backup
- shared reports index

## Park by default

- cloud marketplace
- multi-tenant SaaS
- cross-device sync

## Cost-free rule

No paid services are required for V1 unless explicitly approved.

## Parent reuse map

Usually reuse:

- app shell
- local API host
- SQLite setup
- auth/session
- permissions
- audit log
- reports pattern
- backup pattern where applicable

## Phase 0 output

Before coding, produce a Project Constitution and implementation surface map.
