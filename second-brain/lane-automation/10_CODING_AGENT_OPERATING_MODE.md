# Coding Agent Operating Mode

When assigned an approved lane, the coding agent should work autonomously until automated completion or a real blocker.

## Continue without asking when

- edits are inside lane scope
- repair is directly caused by lane changes
- gates fail with clear fix inside scope
- handoff needs updating

## Stop and ask or block when

- new feature is requested
- product decision missing
- paid dependency introduced
- compliance/current legal rule needed
- protected ref involved
- unrelated refactor needed
