# Manual Check Boundary

Agents can complete automated work, but some checks remain human/manual.

Manual checks include:

- real printer behavior
- actual receipt paper layout
- visual UI readability
- barcode scanner hardware behavior
- installer on clean Windows machine
- real cashier workflow timing
- store-owner acceptance
- legal/compliance approval
- BIR/RMO/eSales production activation

Automated gates do not replace manual validation.
