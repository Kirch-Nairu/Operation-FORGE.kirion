# Handoff Autowrite Protocol

Every lane must end with a handoff.

Suggested path in product repos:

```text
docs/ai-handoffs/YYYY-MM-DD_<branch>_<lane>_handoff.md
```

Required sections:

- Lane
- Branch
- Starting SHA
- Ending SHA
- Status
- What changed
- Files touched
- Gates run
- Gates not run
- Manual checks needed
- Known risks
- Parked scope
- Next recommended lane
