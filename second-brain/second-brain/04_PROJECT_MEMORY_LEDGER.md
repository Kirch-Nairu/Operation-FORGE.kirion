# Project Memory Ledger

This file explains how to record project memory. Use `registries/` files for actual entries.

## Required ledgers

- `registries/PROJECT_REGISTRY.md`
- `registries/LANE_REGISTRY.md`
- `registries/DECISION_LOG.md`
- `registries/PARKED_SCOPE_LEDGER.md`
- `registries/HANDOFF_INDEX.md`

## Entry quality standard

Every memory entry must include:

- date
- project/lane
- decision or fact
- source or evidence
- status
- next action if any

## Bad memory

Do not write:

- "probably done"
- "maybe green"
- "I think this branch is clean"
- "we already handled it" without source
