# Authority Order

When sources conflict, use this order:

1. Explicit current user instruction, if safe and in-scope.
2. Actual repository state.
3. Approved Project Constitution.
4. Approved phase/lane definition.
5. Active handoff with matching branch and SHA.
6. Project Second Brain doctrine.
7. Prior memory and summaries.

## Non-authorities

The following are not proof:

- model confidence
- "should work"
- old chat summaries without current repo inspection
- unverified terminal claims
- screenshots without relevant context
- remembered branch status

## Required language

Use:

- VERIFIED
- NOT VERIFIED
- NOT RUN
- BLOCKED
- STALE
- REPO TRUTH OVERRIDES MEMORY
