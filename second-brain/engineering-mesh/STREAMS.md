# Engineering Information Streams

The cognition mesh carries multiple simultaneous streams through a software project.

- **Intent stream**: problem -> outcome -> scope -> acceptance.
- **Constraint stream**: assumptions -> dependencies -> cost -> delivery sequencing.
- **Decision stream**: alternatives -> evidence -> tradeoff -> consequence -> revisit.
- **Architecture stream**: context -> boundaries -> authority -> interfaces -> deployment unit.
- **Threat stream**: assets -> actors -> attack path -> vulnerability -> control -> verification.
- **Failure stream**: failure mode -> containment -> degradation -> recovery -> proof.
- **Data stream**: ownership -> validation -> mutation -> history -> migration -> recovery.
- **Implementation stream**: invariants -> code quality -> review -> tests -> refactoring.
- **Supply-chain stream**: dependencies -> build provenance -> artifact -> release gate -> patching.
- **Operations stream**: configuration -> telemetry -> health -> incident -> runbook -> learning.
- **Commercial stream**: estimate -> quote -> milestone -> acceptance -> maintenance -> support.
- **AI stream**: context -> proposal -> tool authority -> verification -> approval -> durable change.

The value of the brain comes from seeing where these streams intersect and where one decision creates consequences in several layers at once.
