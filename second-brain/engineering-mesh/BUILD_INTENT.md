# Build Intent

V3 intentionally grows the vault into a large engineering cognition system while preserving native Obsidian graph legibility.

## Non-negotiables

- no custom/static graph renderer
- no decorative links
- no pruning merely for aesthetics
- dense same-domain neighborhoods are desirable
- cross-domain bridges must represent real engineering dependencies
- decisions must expose support, tradeoffs, failure modes, vulnerabilities, mitigations, verification, and revisit triggers
- projects must connect implementation reality back into reusable doctrine
- machine/governance relations may remain nonvisual when they do not represent semantic proximity
