# Codex Repo Study Mode

Use before implementation.

## Commands

```powershell
git branch --show-current
git rev-parse HEAD
git status --short
git log -1 --oneline
```

## Output

- Current branch
- Current SHA
- Git status
- Relevant files found
- Existing patterns
- Likely touched files
- Forbidden files/lanes
- Open questions

## Rules

- No code changes in repo study mode.
- Do not install dependencies.
- Do not create migrations.
- Do not create UI.
- Do not write tests yet.

Repo study ends with a map, not a patch.
