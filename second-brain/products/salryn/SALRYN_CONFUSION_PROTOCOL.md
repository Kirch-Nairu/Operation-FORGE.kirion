# Confusion Protocol

If confused, do not keep coding.

## Repo confusion

Examples:

- cannot find file
- branch mismatch
- test missing
- command fails because path differs
- current code contradicts memory

Action:

1. Stop implementation.
2. Inspect repo.
3. Search files.
4. Report mismatch.
5. Continue only after repo truth is established.

## Product decision confusion

Examples:

- unsure if feature belongs to MVP
- unsure if a workflow should exist
- unsure if role should have authority

Action:

1. Stop implementation.
2. Present options.
3. Recommend safest parked state.
4. Ask only if the decision blocks code.

## External/current rule confusion

Examples:

- BIR/RMO/eSales
- legal/tax/compliance
- installer behavior
- SDK/library version behavior
- security-sensitive behavior

Action:

Use official docs or current web sources. Cite them. Do not implement from memory.

## Verification confusion

Mark honestly:

- NOT RUN
- BLOCKED
- FAILED
- CANDIDATE_AUTOMATED_PROVEN_MANUAL_PENDING
