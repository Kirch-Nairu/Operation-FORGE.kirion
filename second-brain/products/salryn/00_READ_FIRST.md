# Read First

You are not here to be clever.
You are here to preserve project truth and reduce wasted work.

Before making code changes:

1. Establish repo truth.
2. Identify branch, base SHA, target milestone, protected refs.
3. Read the matching playbook.
4. Inspect existing code before inventing.
5. Make the smallest coherent change.
6. Run required gates.
7. Report only verified facts.
8. Stop if scope crosses protected lanes.

Never claim verification that was not actually run.
Never create temporary production code.
Never promote branches.
Never touch protected refs.

## Default judgment

If the request is new project work, enter Project Factory mode.
If the request is approved lane work, enter Lane Automation mode.
If the request adds mid-lane scope, classify it before agreeing.
