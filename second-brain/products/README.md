# Products

Product-specific doctrine lives here, one directory per product. These directories are **not** general engineering doctrine and must not be loaded as such.

General doctrine for Project Second Brain is in [[cognitive-os/00_CONSTITUTION]] through [[cognitive-os/13_LANE_OPERATING_MAP]]. The boundary between this repository and KIRION Forge is in [[SYSTEM_BOUNDARY]].

- [[products/salryn/00_READ_FIRST]] — Salryn

## Why this directory exists

Product doctrine previously occupied the top-level `doctrine/` directory while general doctrine lived in `cognitive-os/`. An agent instructed to "read the doctrine" read one product's rules. The separation is structural so the mistake cannot recur.
