# Cost-Free Development Doctrine

Default development mode is cost-free.

## Prefer

- local-first architecture
- SQLite
- .NET built-ins where reasonable
- free/open-source libraries
- local file storage
- offline operation
- no paid API
- no paid cloud
- no paid database
- no paid reporting tool
- no paid auth provider
- no subscription dependency

## Park by default

- SMS providers
- email delivery providers
- payment gateway integration
- hosted database
- hosted backend
- paid analytics
- paid AI API
- paid OCR
- paid reporting engine

## Cost scan format

```text
Hosting needed: No / Yes / Unknown
Paid API needed: No / Yes / Unknown
Paid database needed: No / Yes / Unknown
Internet required for daily use: No / Yes / Unknown
Subscription dependency: No / Yes / Unknown
Risk: LOW / MEDIUM / HIGH
```
