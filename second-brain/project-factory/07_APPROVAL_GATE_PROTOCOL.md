# Approval Gate Protocol

No project implementation starts without approval.

## Approval words

- APPROVED: proceed to phase planning
- REVISE: update constitution and ask again
- PARK: stop and record in parked scope

## Approval must cover

- MVP includes
- parked scope
- cost-free rule
- parent source strategy
- first phase
- stop conditions

If approval is ambiguous, proceed only with planning, not code.
