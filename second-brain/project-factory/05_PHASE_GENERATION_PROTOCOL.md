# Phase Generation Protocol

Only generate phases after Project Constitution approval.

## Default skeleton

1. Phase 0 — Project Planning and Salryn Parent Study
2. Phase 1 — Data Model and Domain Contracts
3. Phase 2 — Backend Services and Permission Guards
4. Phase 3 — Local API Endpoints
5. Phase 4 — Minimal UI Surface
6. Phase 5 — Workflow Completion
7. Phase 6 — Reports and Exports
8. Phase 7 — Backup/Restore and Settings
9. Phase 8 — Torture Testing
10. Phase 9 — Packaging Candidate

## Each phase must include

- goal
- scope
- forbidden scope
- implementation surfaces
- gates
- manual checks
- definition of done

## Rule

A phase must produce a usable step toward release, not just more architecture.
