# Salryn Standard Parent Repo Protocol

Salryn Standard is a parent source, not a blind template.

Required sequence:

```text
Study → Extract pattern → Adapt only what applies → Prove with gates
```

## Parent study output

- reusable surfaces
- maybe reusable surfaces
- untouched surfaces
- forbidden surfaces
- files/modules to inspect
- likely new modules
- likely migrations
- gate strategy

## Usually reusable

- shell
- WebView
- SQLite setup
- auth/session
- permissions
- audit
- settings
- reports pattern
- CoreSmoke style

## Do not reuse blindly

- POS checkout
- stock deduction
- receipt snapshot semantics
- BIR/RMO/eSales paths
- licensing activation paths
