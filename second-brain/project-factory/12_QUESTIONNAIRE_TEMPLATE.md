# Questionnaire Template

Ask only questions that change implementation.

## Core questions

1. What is the project name?
2. Is this a Salryn skin, Salryn module, or separate product?
3. Who is the first user?
4. What is the one daily workflow it must solve?
5. Must it work offline?
6. Should it reuse Salryn login/users/roles?
7. Should it reuse Salryn business/store identity?
8. Does it need receipts, forms, slips, or reports?
9. Does it need inventory?
10. Does it need money movement?
11. Does it need legal/compliance output?
12. What must be excluded from MVP?
13. What is allowed to be ugly but functional first?
14. What is not allowed to be temporary?
15. What would make V1 done?
