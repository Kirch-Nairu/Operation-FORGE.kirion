# Lesson System

A lesson captures what an observed project outcome changed about our understanding.

## Lesson sources

- incident / near miss
- retrospective
- failed hypothesis
- successful repeated pattern
- performance/security hardening
- deployment/recovery exercise
- user/client validation

## Promotion path

```text
OBSERVATION
→ LESSON
→ REPEATED EVIDENCE
→ PATTERN / ANTI-PATTERN
→ DOCTRINE CHANGE only with explicit review
```

One severe, well-understood event may justify doctrine change when consequence warrants it, but the reasoning must be explicit.
