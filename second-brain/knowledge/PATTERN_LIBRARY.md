# Pattern Library

Patterns are reusable approaches backed by project evidence. They are not universal laws.

## Every mature pattern should say

- problem it solves
- context
- when to use
- when not to use
- forces / trade-offs
- implementation shape
- risks
- evidence/projects
- counterexamples
- maturity/certainty
