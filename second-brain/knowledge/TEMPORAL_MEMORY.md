# Temporal Memory

The brain preserves evolution instead of rewriting history into the latest answer.

## Preserve

- superseded architecture decisions
- old assumptions and the evidence that supported them
- project phase/release milestones
- incidents tied to releases
- changes in risk acceptance
- pattern maturity over time
- doctrine revisions and the evidence/reason for change

## Questions this enables

- What did we believe at a specific time?
- Which evidence supported that belief?
- What changed?
- Which decision superseded the old one?
- Which release introduced or removed a behavior?
- Which incident invalidated an assumption?

## Rule

Supersession adds a relationship; it does not erase the superseded object.
