# Pattern Promotion Protocol

Do not generalize one project's accidental shape into universal doctrine.

## Promotion checks

1. Is the underlying problem recurring?
2. Are project contexts genuinely comparable?
3. Is there evidence the approach caused the outcome rather than merely coexisting with it?
4. Are failure cases/counterexamples known?
5. Can we state when **not** to use it?
6. What certainty level is justified?
