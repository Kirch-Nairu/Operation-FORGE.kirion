# Supporting Evidence Packet

## Required evidence questions
- What repository or runtime facts are directly observed?
- Which claims come from standards, documentation, tests, measurements, incidents, or stakeholder authority?
- Which assumptions remain unverified?
- How fresh and reproducible is the evidence?
- What evidence would change the decision?
