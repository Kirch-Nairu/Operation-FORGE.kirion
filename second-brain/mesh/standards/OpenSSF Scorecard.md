# OpenSSF Scorecard

OpenSSF Scorecard performs automated checks that help assess security risks in open-source projects and dependencies. It is useful as one input to dependency acceptance and improvement, not as a substitute for project-specific threat modeling or review.

Source: https://openssf.org/projects/scorecard/
