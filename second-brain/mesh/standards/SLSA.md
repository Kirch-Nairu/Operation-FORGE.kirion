# SLSA

SLSA (Supply-chain Levels for Software Artifacts) is a set of incrementally adoptable supply-chain security guidelines. Its current documentation is version 1.2. The build track increases assurance from provenance through hosted and hardened build infrastructure so consumers can better trust how software artifacts were produced.

Source: https://slsa.dev/
