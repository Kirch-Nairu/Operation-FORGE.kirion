# Memory Safety Strategy

Memory safety is a design consideration when choosing languages, runtimes, FFI boundaries, unsafe code, and components that process untrusted input. CISA has urged software manufacturers to develop memory-safe roadmaps where practical because memory-safe languages can eliminate broad classes of vulnerabilities.

Source: https://www.cisa.gov/resources-tools/resources/case-memory-safe-roadmaps
