# OWASP ASVS 5

OWASP Application Security Verification Standard 5.0.0 was released on 30 May 2025. ASVS provides a structured basis for verifying application security requirements across architecture, authentication, session management, access control, validation, cryptography, logging, data protection, and other security areas.

Source: https://owasp.org/www-project-application-security-verification-standard/
