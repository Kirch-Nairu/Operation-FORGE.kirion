# NIST SSDF

NIST SP 800-218 defines the Secure Software Development Framework: high-level practices that can be integrated into an SDLC to reduce released vulnerabilities, reduce the impact of undetected vulnerabilities, and address root causes. Version 1.1 is the current final publication; NIST published an initial public draft of Version 1.2 as SP 800-218 Rev. 1 in December 2025.

Source: https://csrc.nist.gov/pubs/sp/800/218/final
Draft 1.2: https://csrc.nist.gov/pubs/sp/800/218/r1/ipd
