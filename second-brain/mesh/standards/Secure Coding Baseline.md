# Secure Coding Baseline

The secure coding baseline requires explicit authority checks, boundary validation, safe output handling, secret isolation, safe defaults, dependency hygiene, security-relevant logging, invariant protection, and rejection of unsafe error fallbacks. Controls are verified where consequence warrants it.
