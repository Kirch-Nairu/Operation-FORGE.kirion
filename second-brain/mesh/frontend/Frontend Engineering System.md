# Frontend Engineering System

Frontend engineering owns user-visible state, accessibility, validation feedback, loading/error behavior, offline and optimistic behavior, performance, session UX, sensitive-data exposure, and interaction with API contracts. The browser is an untrusted client: UI authorization never replaces server authority.
