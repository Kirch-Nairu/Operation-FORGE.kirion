# High Quality Code

High-quality code is correct under intended and invalid inputs, explicit about authority and state, readable in domain terms, easy to review, protected by proportional tests, observable in operation, secure by default, and structured so future change has a bounded surface.

It does not optimize one property in isolation. Clever but unverifiable code, clean code with weak authorization, or heavily tested code with bad data authority are all low-quality outcomes.
