# Quote Construction

A technical quote makes commercial assumptions explicit. A robust quote separates base engineering effort, infrastructure/licenses, integration, data migration, security/hardening, testing, deployment, documentation/turnover, contingency, support, maintenance, and margin.

## Quote skeleton
`price = base effort + external cost + risk/uncertainty + delivery overhead + support obligation + margin`
