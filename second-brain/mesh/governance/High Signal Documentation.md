# High Signal Documentation

> Documentation exists to reduce uncertainty, coordination cost, and future reconstruction.

Useful documentation records authority, rationale, boundaries, contracts, assumptions, failure behavior, recovery, and decisions. Documentation that merely repeats code or process without changing understanding should be simplified.
