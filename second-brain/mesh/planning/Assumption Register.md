# Assumption Register

An assumption is a belief currently required for progress but not yet proven. Important assumptions record evidence strength, owner, blast radius if false, expiry/review date, and the decision or plan they support.

## Failure questions
- Which assumption can invalidate the architecture?
- Which assumption is being treated as fact?
- When must the assumption be rechecked?
