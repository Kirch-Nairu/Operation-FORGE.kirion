# Planning System

Planning converts an ambiguous request into an executable engineering boundary. It exposes the problem, desired outcome, constraints, assumptions, non-goals, dependencies, acceptance conditions, and sequencing before implementation pressure hides uncertainty.

## Questions
- What problem is actually being solved?
- What is explicitly outside scope?
- Which assumptions would invalidate the plan if false?
- Which dependencies control sequence or feasibility?
- What evidence will prove the phase is complete?
