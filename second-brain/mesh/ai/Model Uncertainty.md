# Model Uncertainty

Model uncertainty is the gap between fluent output and justified knowledge. It increases when context is missing, APIs are unfamiliar, state is changing, private data is unavailable, or the task requires exact runtime facts. Uncertainty should change behavior: inspect, verify, narrow, or ask.
