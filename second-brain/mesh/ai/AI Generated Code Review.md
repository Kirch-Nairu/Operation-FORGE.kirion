# AI Generated Code Review

AI-generated code is reviewed for the same correctness, authority, data, security, failure, migration, test, observability, and maintainability properties as human code, with extra attention to fabricated APIs, overbroad changes, duplicated logic, unsafe defaults, and unsupported claims.
