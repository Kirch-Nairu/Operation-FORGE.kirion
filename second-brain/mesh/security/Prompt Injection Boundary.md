# Prompt Injection Boundary

Prompt injection occurs when untrusted content attempts to influence an AI system's instructions, authority, tool use, or data disclosure. The defense is architectural: separate instructions from untrusted data, constrain tools, minimize privileges, verify high-impact actions, and treat retrieved content as untrusted evidence.
