# Nest Authorization Protocol

Existing projects require explicit authorization before Forge governance is written into the repository.

## Preconditions

- repository identified;
- reconnaissance completed to the agreed depth;
- material findings reported;
- proposed Forge impact explained.

## Canonical request

A Maintainer should ask substantially:

> Reconnaissance is complete. Do you authorize KIRION Forge to nest into this repository and establish repository-specific durable memory, authority records, agent operating instructions, engineering continuity, handoff structures, and governance?

## If authorization is denied

Return the audit/reconnaissance result. Do not install Forge governance artifacts.

## If authorization is granted

Proceed to baseline capture and Nesting.

## Scope

Nest Authorization grants authority to establish the approved Forge governance structure. It does not automatically grant authority for unrelated application rewrites, destructive migrations, infrastructure changes, or deployment.
