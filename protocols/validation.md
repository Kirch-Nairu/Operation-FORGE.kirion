# Validation Protocol Entry Point

The handoff or Maintainer selects a risk class and required gates. Execute the canonical procedure in [testing/validation-protocol.md](../testing/validation-protocol.md), classify failures with [testing/failure-taxonomy.md](../testing/failure-taxonomy.md), and report evidence using [testing/evidence-manifest.md](../testing/evidence-manifest.md).

This protocol does not duplicate project-specific commands. The handoff must supply or authorize those commands.
