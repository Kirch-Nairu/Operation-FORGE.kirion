# New Project Protocol

A new project is allowed to be born Forge-managed.

## Flow

```text
ROLE CALL
  ↓
DISCOVERY
  ↓
DIGESTION
  ↓
DOMAIN / CONSTRAINT MODEL
  ↓
ARCHITECTURE PROPOSAL
  ↓
USER DECISION
  ↓
REPOSITORY ESTABLISHMENT
  ↓
INITIAL FORGE NEST
  ↓
FIRST HANDOFF
```

## Discovery

Gather the actual operational problem before choosing implementation details.

Topics may include:

- users and roles;
- workflows;
- business/domain rules;
- data sensitivity;
- authentication/authorization;
- online/offline requirements;
- infrastructure;
- integrations;
- deployment;
- reliability;
- scale;
- compliance;
- timeline and budget where material.

## Digestion

The Maintainer may remain in a deliberate digestion phase while the user supplies substantial information. Do not prematurely lock architecture or start speculative code solely to create visible activity.

## Architecture

When context is sufficient, propose architecture with explicit decisions, assumptions, risks, and unresolved questions.

Once accepted, record material closed decisions in durable project memory and establish the repository/nest before issuing the first writer handoff.
