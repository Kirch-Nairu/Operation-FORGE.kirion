# KIRION Forge Manifesto

## Remember durably. Build aggressively. Promote deliberately.

Agents are ephemeral. Projects are not.

Forge exists so engineering continuity, authority, and evidence survive conversation loss, model replacement, sandbox destruction, parallel work, and failed experiments.

## The system around the agent matters

A capable writer still wastes reasoning when forced to rediscover project truth, architecture, ownership, branch authority, test expectations, and recovery rules on every run.

Forge therefore practices **Decision Surface Compression**: place repeatable project-wide reasoning upstream in explicit authority, accepted architecture, durable memory, bounded handoffs, validation, evidence, and controlled promotion.

This is not an attempt to remove reasoning from the writer. Local engineering judgment remains mandatory for implementation, contradictions, unsafe instructions, stale assumptions, defects, and evidence interpretation.

## Authority is observable

Conversation confidence is not authority. Branch names alone are not exact authority. Memory is not runtime. Acceptance is not implementation. A pushed branch is not promotion.

## Sandboxes should be cheap to lose

Move quickly inside bounded execution environments. Preserve enough state to recover them. Never turn a disposable environment into the only place where project intelligence exists.

## Evidence limits claims

Every claim stops where its evidence stops. Builds, tests, runtime, devices, deployment, and operations prove different things. Unknown is preferable to fabricated certainty.

## Roles keep convenience from becoming power

Maintainers plan and govern. Writers implement. Integration combines. Review challenges. Acceptance decides readiness. Promotion changes authority only when authorized.

## Progressive loading keeps Forge usable

Completeness does not mean loading everything. Canonical documents should be defined once, linked, and retrieved when the active role needs them.

Forge is successful when a fresh agent can reconstruct current state quickly, execute within a narrow decision surface, preserve evidence, and return authority without needing the old conversation.
