# Controlled Learning Boundary

A successful stronger-model or teacher trace is evidence that a procedure may be useful. It is not permission to rewrite Forge doctrine or install an authoritative skill.

```text
failure
→ teacher/stronger worker succeeds
→ trace captured
→ generalized procedure
→ SKILL CANDIDATE
→ independent review
→ REVIEWED_APPROVED / REVIEWED_REJECTED
→ separate promotion authority if promotion is ever desired
```

The teacher may not review its own learned procedure.

Both candidate and reviewed result carry no execution authority and no promotion authorization. Review approval means “worthy of promotion consideration,” not “installed.”

This prevents one successful workaround, environment-specific trick, unsafe bypass, or accidental behavior from becoming durable procedure merely because it worked once.

Runtime reference: `tools/forge_learning_kernel.py`.
