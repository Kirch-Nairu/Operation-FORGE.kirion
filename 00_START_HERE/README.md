## Important

These files are launchers, not a second copy of Forge doctrine.

They deliberately stay small and instruct the agent to load the canonical repository sources:

1. `BOOTSTRAP.md`
2. `BOOTSTRAP_CHATGPT.md` when using ChatGPT
3. `AGENTS.md`
4. the active role contract
5. current project authority and durable memory
6. the current handoff
7. only the protocols needed for the next decision

Do **not** paste the entire Forge repository into the conversation as text. Attach/provide the repository and let the agent progressively load what it needs.

The handoff is the first-line execution surface. The repository remains the durable source of doctrine, authority rules, memory structure, evidence rules, and operating protocols.
