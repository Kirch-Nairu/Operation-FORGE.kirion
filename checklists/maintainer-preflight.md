# Maintainer Preflight

- [ ] Active role is Maintainer.
- [ ] Repository/remote identity is verified.
- [ ] Current authority branch and full SHA are observed.
- [ ] SSOT, authority, nest, and relevant active decisions are loaded.
- [ ] Runtime/deployment state is distinguished from Git state where relevant.
- [ ] Active writers/candidates and ownership collisions are known.
- [ ] Objective and risk class are defined.
- [ ] Architecture decisions required before delegation are closed or explicitly left to bounded writer judgment.
- [ ] Validation/acceptance requirements are selected.
- [ ] Destructive actions, if any, have separate explicit authority.
- [ ] Stop conditions are defined.
