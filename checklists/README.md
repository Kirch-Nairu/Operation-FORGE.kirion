# Forge Checklists

## What is this?

These checklists compress repeated preflight, acceptance, promotion, release, recovery, and nest-maturity reasoning into concrete questions that can be answered from observable state.

## When do I load it?

Load only the checklist for the active transition. Do not load the whole directory by default.
