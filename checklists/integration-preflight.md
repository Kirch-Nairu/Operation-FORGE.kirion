# Integration Preflight

- [ ] Role has explicit integration authority.
- [ ] Every source candidate SHA is exact.
- [ ] Acceptance/status of each source is known.
- [ ] Integration target source SHA is exact.
- [ ] Required order and precedence are explicit.
- [ ] Ownership/collision decisions are recorded.
- [ ] Integration-only fix scope is defined.
- [ ] Combined validation is selected.
- [ ] Promotion authority is not assumed.
