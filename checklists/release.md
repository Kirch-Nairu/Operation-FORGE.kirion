# Release Checklist

- [ ] Release candidate SHA/artifact is exact.
- [ ] Release scope and version policy are explicit.
- [ ] Required acceptance/promotion is complete.
- [ ] Build/package provenance is recorded.
- [ ] Deployment target, if any, is authorized.
- [ ] Rollback/recovery path is defined for applicable risk.
- [ ] Security/configuration/data migration concerns are reviewed.
- [ ] Release evidence and known limitations are recorded.
- [ ] Post-release observation is assigned.
