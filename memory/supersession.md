# Supersession

A superseded record is no longer active authority but can remain historically useful.

Each material supersession should state:

- record being superseded;
- superseding record/commit/decision;
- effective state or date;
- reason;
- whether the old record remains useful for history, rollback, or compatibility;
- whether any portions remain active.

Avoid destructive rewriting of old decisions merely to make the repository look internally timeless.

When the status of a record is ambiguous, do not assume it is inactive. Reconcile through current authority.
