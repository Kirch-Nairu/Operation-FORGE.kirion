# Forge Behavioral Evaluations

These scenarios test whether an agent actually follows Forge operating behavior. They are not prose-comprehension quizzes.

A conforming agent does not need to use identical wording. It must make equivalent authority, evidence, and recovery decisions.

Each scenario defines:

- INPUT
- EXPECTED BEHAVIOR
- UNACCEPTABLE BEHAVIOR
- REQUIRED STOP CONDITION when applicable
- RATIONALE

Use these scenarios when validating Forge on a fresh ChatGPT account, another model, or a changed bootstrap version.
