# Nest Lifecycle

Typical lifecycle:

```text
UNNESTED
→ RECONNAISSANCE
→ NEST AUTHORIZED
→ NEST MATERIALIZED
→ GOVERNED
→ HARDENED / OPERATED
→ SELF-HOSTING only after explicit evidence
```

For new projects, a project may be born nested without inherited-project authorization.

Maturity labels are verified against [checklists/nest-maturity.md](../checklists/nest-maturity.md). A candidate may add prerequisites without upgrading the accepted nest record.
