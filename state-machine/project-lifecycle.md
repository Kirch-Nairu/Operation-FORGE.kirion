# Project Lifecycle

Forge project state is broader than one branch:

```text
DISCOVERY / RECONNAISSANCE
→ GOVERNED PLAN
→ CANDIDATE EXECUTION
→ REVIEW / ACCEPTANCE
→ INTEGRATION
→ PROMOTION
→ RELEASE / DEPLOYMENT where applicable
→ OBSERVATION
→ INCIDENT / RECOVERY when required
→ CONTINUITY
```

Not every project deploys. Not every candidate becomes a release.

Current project state belongs in repository-local durable memory and observable systems, not only in conversation.
