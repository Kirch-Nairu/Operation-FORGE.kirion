# Forge State Machines

## What is this?

These documents make lifecycle states and legal transitions explicit. They are governance models; they are not automatically enforced unless tooling says so.

## When do I load it?

Load the specific lifecycle when planning, reviewing, integrating, promoting, or diagnosing an illegal transition.

## What is canonical?

- [candidate-lifecycle.md](candidate-lifecycle.md)
- [role-transitions.md](role-transitions.md)
- [nest-lifecycle.md](nest-lifecycle.md)
- [project-lifecycle.md](project-lifecycle.md)

## Dependencies

State transitions depend on authority, evidence, and role boundaries.
